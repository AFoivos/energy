# Σκοπός και όρια

## Κατάσταση

Έχει εγκριθεί ο σκελετός του project και η συγγραφή της αρχικής τεκμηρίωσης. Τα Python αρχεία είναι κενά. Δεν έχουν εισαχθεί δεδομένα ούτε εκτελεστεί μοντέλα, tests ή backtests.

## Επιχειρησιακό ερώτημα

Εξετάζουμε αν οι προβλέψεις και η βελτιστοποίηση λειτουργίας μπαταρίας αυξάνουν την καθαρή αξία ενός χαρτοφυλακίου ΑΠΕ, σε σύγκριση με απλές πολιτικές συμμετοχής στην αγορά, υπό φυσικούς περιορισμούς και αβεβαιότητα.

Το case study αφορά υποθετικό χαρτοφυλάκιο. Δεν αποτελεί αναπαράσταση assets ή εσωτερικών διαδικασιών της METLEN.

## Αρχικές παράμετροι προς οριστικοποίηση

| Asset | Ενδεικτικό μέγεθος |
| --- | --- |
| Φωτοβολταϊκά | 50 MW |
| Αιολικά | 30 MW |
| Μπαταρία | 20 MW / 40 MWh |

Απόδοση, λειτουργικά όρια, κόστος φθοράς, σημείο σύνδεσης και αρχική ενέργεια δεν έχουν ακόμη βαθμονομηθεί. Θα τεκμηριωθούν πριν από πείραμα.

## Εντός αντικειμένου

- Python και XLSX ως πρωτογενή δεδομένα.
- Χρονικά ορθή εισαγωγή, έλεγχος και χρήση δεδομένων.
- Forecasting με baselines και scikit-learn ή statsmodels.
- LP/MILP με scipy.optimize.linprog και scipy.optimize.milp.
- Ιστορική προσομοίωση, εκκαθάριση και έλεγχος κινδύνου.
- Αναφορές Excel και τοπικό dashboard.
- Τεκμηρίωση υποθέσεων, περιορισμών και αρνητικών αποτελεσμάτων.

## Όρια

Δεν περιλαμβάνονται πραγματικές εντολές, σύνδεση με broker, cloud υποδομή ή υποχρεωτική βάση δεδομένων. Η εκκαθάριση αποκλίσεων δεν συνεπάγεται ότι το χαρτοφυλάκιο μπορεί να παρέχει υπηρεσίες εξισορρόπησης. Τέτοια συμμετοχή απαιτεί διαφορετικούς κανόνες και δεν αποτελεί αρχική υπόθεση.

Δεν θεωρούμε ότι ένα συγκεντρωτικό εθνικό προφίλ είναι μέτρηση συγκεκριμένου πάρκου. Κάθε συνθετικό ή αναλογικά κλιμακωμένο προφίλ θα επισημαίνεται.

## Σύνδεση με τη θέση

| Πεδίο | Παραδοτέο |
| --- | --- |
| Algorithmic trading | Ελεγχόμενες πολιτικές θέσεων και διορθώσεων |
| Optimization | Φυσικά εφικτός προγραμματισμός μπαταρίας |
| Market analysis | Ερμηνεία τιμών, παραγωγής και αποκλίσεων |
| Performance monitoring | Πρόσθετη αξία, κίνδυνος και attribution |
| Automation | Επαναλήψιμη επεξεργασία XLSX |
| Operations | Έλεγχοι, συμβάντα και αναφορά βάρδιας |

## Κριτήρια ολοκλήρωσης

Απαιτούνται ελεγμένα δεδομένα, baseline, ανεξάρτητοι έλεγχοι λύσεων, αναπαραγώγιμη εκκαθάριση, χρονικός έλεγχος εκτός δείγματος και τεκμηριωμένα όρια. Θετικό κέρδος δεν αποτελεί προϋπόθεση αποδοχής της έρευνας. Μη υποστηριζόμενος ισχυρισμός κερδοφορίας αποτελεί λόγο απόρριψης.
