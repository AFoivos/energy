# Συμβόλαιο δεδομένων

## Κατάσταση

Πρόταση εσωτερικού σχήματος πριν από την επιθεώρηση των πρώτων XLSX. Οι αρχικές στήλες των πηγών θα αντιστοιχιστούν ρητά σε αυτό το σχήμα. Δεν έχουν επικυρωθεί πραγματικά δεδομένα.

## Βασικά πεδία

| Πεδίο | Σημασία |
| --- | --- |
| source_id | Πηγή και τύπος dataset |
| source_file / source_sheet | Αρχείο και φύλλο προέλευσης |
| source_checksum | Ταυτοποίηση αρχικών bytes |
| revision_id | Έκδοση της συγκεκριμένης δημοσίευσης |
| asset_id / bidding_zone | Asset ή γεωγραφικό πεδίο |
| market / product | Αγορά και προϊόν, όπου ισχύει |
| delivery_start / delivery_end | Ημι-ανοικτό διάστημα παράδοσης [start, end) |
| issued_at | Χρόνος έκδοσης πρόβλεψης ή δημοσίευσης |
| available_at | Πρώτος τεκμηριωμένος χρόνος χρήσης από το μοντέλο |
| retrieved_at | Χρόνος λήψης του αρχείου |
| value / unit | Τιμή και φυσική ή οικονομική μονάδα |
| quality_flag | Πραγματικό, αναθεωρημένο, proxy, συνθετικό ή ελλιπές |

Τα πεδία έκδοσης και δημοσίευσης μπορεί να είναι άγνωστα. Δεν συμπληρώνονται με αυθαίρετο χρόνο ώστε να περάσει ένας έλεγχος.

## Χρόνος

Εσωτερικά χρησιμοποιούμε timezone-aware UTC. Η Europe/Athens χρησιμοποιείται για παρουσίαση και ερμηνεία των τοπικών αρχείων. Διφορούμενες ή ανύπαρκτες ώρες λόγω θερινής ώρας απαιτούν ρητό χειρισμό.

Η ημερήσια διάρκεια δεν θεωρείται πάντα 24 ώρες. Η διάρκεια κάθε περιόδου προκύπτει από τα όριά της.

Για απόφαση στον χρόνο t απαιτείται available_at <= t. Η αναπαραγωγή επιλέγει την πιο πρόσφατη επιτρεπτή έκδοση, όχι την τελευταία έκδοση που κατεβάσαμε σήμερα.

Ο χρόνος απόφασης δεν ταυτίζεται υποχρεωτικά με την αρχή παράδοσης.

## Μονάδες και συγκέντρωση

- Ισχύς: MW.
- Ενέργεια: MWh.
- Τιμή: EUR/MWh.
- Κόστος και έσοδο: EUR.
- Απόδοση: λόγος στο διάστημα (0, 1].

Για μέση ισχύ περιόδου: ενέργεια = ισχύς × διάρκεια σε ώρες. Η συγκέντρωση ισχύος είναι χρονικά σταθμισμένη, ενώ η ενέργεια αθροίζεται. Δεν μετατρέπουμε ωριαίες τιμές σε πραγματικά 15λεπτα δεδομένα μέσω απλής επανάληψης χωρίς σήμανση.

## Έλεγχοι

1. Αναμενόμενα φύλλα και υποχρεωτικές στήλες.
2. Αναγνώσιμοι αριθμοί, διαχωριστικά δεκαδικών και μονάδες.
3. Μοναδικότητα σύνθετου κλειδιού μαζί με την έκδοση.
4. delivery_end > delivery_start.
5. Ανίχνευση κενών, επικαλύψεων και απρόσμενης ανάλυσης.
6. Έλεγχος φυσικών ορίων παραγωγής όπου είναι γνωστά.
7. Αποδοχή αρνητικών τιμών ηλεκτρικής ενέργειας.
8. Διατήρηση μηδενικής παραγωγής ως έγκυρης τιμής.
9. Διαχωρισμός actual, forecast και revised actual.
10. Έλεγχος χρόνου διαθεσιμότητας πριν από χρήση σε features.

Δεν εφαρμόζεται αυτόματο forward-fill σε πραγματικά κενά. Δεν διαγράφονται ακραίες τιμές μόνο επειδή δυσκολεύουν το μοντέλο.

## XLSX ιδιαιτερότητες

Το openpyxl δεν υπολογίζει τύπους Excel. Cached αποτελέσματα τύπων μπορεί να λείπουν ή να είναι παλιά. Ο reader θα ανιχνεύει τέτοιες περιπτώσεις και θα ζητά τεκμηριωμένη εξαγωγή τιμών πριν από χρήση.

Τα μεγέθη που θα εξάγονται σε Excel θα συνοδεύονται από μονάδες. Οι χρόνοι UTC θα εξάγονται ως σαφή ISO 8601 strings ή με ξεχωριστή στήλη ζώνης ώρας, επειδή τα Excel datetime cells δεν διατηρούν timezone.
