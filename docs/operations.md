# Λειτουργία και χειρισμός αστοχιών

## Πεδίο

Η εφαρμογή θα κάνει τοπική αναπαραγωγή ιστορικών XLSX. Δεν συνδέεται σε πραγματικό exchange και δεν υποβάλλει πραγματικές εντολές. Τα παρακάτω είναι προδιαγραφή μελλοντικής λειτουργίας.

## Έλεγχοι πριν από απόφαση

- Διαθέσιμα υποχρεωτικά δεδομένα και σωστό available_at.
- Μονάδες, πλήρης χρονική περίοδος και έγκυρη έκδοση.
- Συμφωνία θέσης με τα καταγεγραμμένα fills.
- Ενέργεια μπαταρίας εντός ορίων.
- Ανοιχτό επιτρεπτό παράθυρο απόφασης.
- Επαρκής πληροφορία εκτέλεσης ή σαφώς δηλωμένη υπόθεση.

Η ηλικία πληροφορίας υπολογίζεται έναντι του χρόνου προσομοίωσης, όχι έναντι της σημερινής ημερομηνίας.

## Πίνακας αστοχιών

| Περίπτωση | Προβλεπόμενη συμπεριφορά |
| --- | --- |
| Απουσία υποχρεωτικού XLSX | Διακοπή έναρξης και αναφορά ελλείποντος αρχείου |
| Μονάδες ή timestamps άγνωστα | Απόρριψη dataset μέχρι διευκρίνιση |
| Παρωχημένη πληροφορία | Αποκλεισμός εξαρτώμενων νέων ενεργειών |
| Solver infeasible ή χωρίς λύση | Καμία χρήση του αποτελέσματος ως εντολής |
| Time limit με incumbent | Χρήση μόνο αν περάσει ανεξάρτητους ελέγχους και την προκαθορισμένη πολιτική gap |
| Παραβίαση risk limit | Απόρριψη πρότασης με αιτία |
| Μερική εκτέλεση | Μεταβολή θέσης μόνο κατά την εκτελεσμένη ποσότητα |
| Επανεκκίνηση | Επαναφορά ελεγμένου checkpoint και αποφυγή διπλών fills |
| Μεταγενέστερη αναθεώρηση settlement | Νέα έκδοση λογιστικού record, χωρίς διαγραφή ιστορικού |

Το μπλοκάρισμα νέων εντολών δεν εξαλείφει υπάρχουσες υποχρεώσεις ή κίνδυνο. Το fallback πρόγραμμα φυσικής λειτουργίας θα οριστεί και θα ελεγχθεί για το συγκεκριμένο asset.

## Καταγραφή

Κάθε απόφαση θα συνδέεται με χρόνο, snapshot, έκδοση δεδομένων, forecast, configuration, solver status, ελέγχους, order/fill identifiers και αιτιολόγηση. Τα logs δεν περιέχουν credentials.

## Αναφορά παράδοσης βάρδιας

Ανοικτές θέσεις ανά παράδοση, ενέργεια μπαταρίας, εκκρεμείς ενέργειες, κατάσταση δεδομένων, ενεργά όρια, αποτυχίες, προσωρινή αποτίμηση και μη οριστικοποιημένη εκκαθάριση.

## Επίδειξη

Θα επιλεγούν τρία αναπαραγώγιμα σενάρια: κανονική λειτουργία, απότομη αναθεώρηση πρόβλεψης και αστοχία δεδομένων/solver. Το demo θα δηλώνει ότι είναι ιστορική προσομοίωση.

## Παρούσα κατάσταση

Δεν έχουν υλοποιηθεί alerts, checkpointing, dashboard ή recovery. Δεν έχει δοκιμαστεί επιχειρησιακή διαθεσιμότητα.
