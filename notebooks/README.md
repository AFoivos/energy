# Notebooks

Δεν έχουν δημιουργηθεί notebooks ακόμη. Ένα κενό αρχείο .ipynb δεν είναι έγκυρο notebook.

Η αρχική σειρά ανάλυσης θα είναι επιθεώρηση XLSX, έλεγχοι δεδομένων, baseline, μπαταρία, forecasting και σύγκριση στρατηγικών. Τα ακριβή filenames θα οριστούν όταν υπάρχουν πραγματικά δεδομένα και συγκεκριμένα ερωτήματα.

Τα notebooks καλούν το aegean package. Δεν αντιγράφουν τη λογική εκκαθάρισης, βελτιστοποίησης ή feature engineering.

Κάθε notebook θα αναφέρει ερώτημα, πηγές, configuration, χρονικό δείγμα, μονάδες, αποτελέσματα και περιορισμούς. Πριν δημοσιευτεί απαιτείται καθαρή επανεκτέλεση με δηλωμένο περιβάλλον και έλεγχος ότι τα outputs δεν αποκαλύπτουν μη αναδιανεμόμενα δεδομένα.
