# Αποτελέσματα

| Φάκελος | Περιεχόμενο |
| --- | --- |
| reports/ | Αναφορές και εξαγωγές XLSX |
| figures/ | Γραφήματα που παράγονται από Python |
| logs/ | Συμβάντα, diagnostics και στοιχεία run |

Οι φάκελοι είναι προς το παρόν κενοί. Τα παραγόμενα αρχεία εξαιρούνται από το Git.

Κάθε run θα έχει μοναδικό αναγνωριστικό και σύνδεση με configuration, δεδομένα και εκδόσεις κώδικα/περιβάλλοντος. Δεν αντικαθιστούμε σιωπηρά τα αποτελέσματα παλιότερου πειράματος.

Οι αναφορές θα ξεχωρίζουν forecast, προγραμματισμένη ενέργεια, fills, φυσική παράδοση, προσωρινή αποτίμηση και τελική εκκαθάριση. Δεν αναφέρεται αποτέλεσμα πριν εκτελεστεί και επαληθευτεί το αντίστοιχο πείραμα.
